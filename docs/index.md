# Benchmark Set Selection Tool

A tool to sample a representative benchmark set from a larger collection of instances.
`setselector` combines solver runtimes with instance features, removes unusable
or uninformative instances, clusters the remaining instances, and samples from
the runtime distribution while limiting cluster overrepresentation.
