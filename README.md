# Benchmark Set Selection Tool

A tool for sampling a benchmark set from a larger collection or distribution of
diverse instances.

## Installation

Install the project with:

```bash
pip install .
```

## Usage

For basic usage information, run:

```bash
setselector -h
```

The tool requires runtime and feature data in CSV files. The runtime file must
contain a header with solver IDs and one row for each instance. The first
column contains the instance name, followed by the runtime of each solver on
that instance. The feature file must contain a header with feature IDs and one
row for each instance. Its first column contains the instance name, followed by
the feature values for that instance. Examples are available in `./example/`.

The following command selects approximately five instances with a runtime
cutoff of 300. Instances on which all solvers time out are excluded by default;
use `--keep-too-hard` to retain them. Instances for which all solvers finish
below `cutoff * easyK` are also excluded by default; use `--keep-too-easy` to
retain them. Use `--log=info` for more detailed output.

> [!NOTE]
> The number of instances returned does not always match the requested number.\
> The number of clusters is determined automatically, and overrepresentation of
> clusters is avoided.\
> This is more likely to occur with small instance sets.

```bash
setselector --runtimes ./example/times.csv --features ./example/features.csv --n 5 --cutoff 300
```

Alternatively, an evaluation XML file generated by the
[potassco-benchmark-tool](https://potassco.org/benchmark-tool/) can be
provided:

```bash
setselector --eval eval.xml --n 5 --cutoff 300
```

Evaluation features can be selected with `--eval-features` by providing a
comma-separated list. The default features are `rules_s,bodies_s`.
